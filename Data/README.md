 author: 	Natascha Stoffel, natascha.stoffel@unifr.ch
 
Please note that the data provided here is NOT the complete list of participants, as not all participants provided consent on using the data further.
Thus here you find a subset of participants (N = 81)
	
-  Data Dictionary
-  excel file with CRF data from those people who gave consent on further use of the data
- exec files named FND/HC_electrodes_average_250-595ms_forsharing ; this is the extracted EEG data (averaged trace for the time interval of 250-595ms) separate per group and condition, which is used to calculate targeted (control) analysis of specific sites

ALSO please note: the EEG data from the people who gave consent on further use of the data can be found : www.doi.org/10.5281/zenodo.15010968
