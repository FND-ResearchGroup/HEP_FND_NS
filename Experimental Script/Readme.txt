This folder contains the scripts used during experimental session. 
It would require the software E-Prime3 (Psychology Software tools, Pittsburgh, USA) to be opened of executed. 
It also contains the questionnaires related to each task.

HCT task
The script "task_HCT.ebs3" was executed. It include a training trial and then the real experimental recording. 


HEP task: 
First, the script "task3_HEP_TRAINING.ebs3" was executed to familiarized the participant with the task.
Then, the script "task3_HEP.ebs3" was executed for the experimental recording.
